## 2024-05-24 - Improve Accessibility for Tabs and Dynamic Results
**Learning:** For elements whose content dynamically changes after an interaction (e.g. dice roll total), `aria-live="polite"` and `aria-atomic="true"` are critical to ensure screen readers announce the updated content without interrupting the user. Also, tab navigation needs `role="tablist"`, `role="tab"`, and `role="tabpanel"` relationships with dynamic `aria-selected` toggling for proper keyboard/screen-reader navigation. Explicit `focus-visible` styling is necessary for custom buttons to show keyboard focus.
**Action:** Next time creating a custom tab component or dynamic result container, include these ARIA roles, states (`aria-selected`), relationships (`aria-controls`, `aria-labelledby`), and `aria-live` behavior from the start. Add `focus-visible` styling (like `focus-visible:ring-2 focus-visible:outline-none`) to interactive elements.
